# GPT Code 文档索引

GPT Code V0.1.x 的产品、架构、开发与 Windows 交付文档统一放在本目录。目录名 `deskpilot` 暂时作为内部兼容路径保留。

- [`PRD.md`](./PRD.md)：产品需求与技术开发设计文档。
- [`ARCHITECTURE.md`](./ARCHITECTURE.md)：DeskPilot 在上游项目上的架构落地方案。
- [`SOURCE_AUDIT.md`](./SOURCE_AUDIT.md)：上游源码审计、复用边界与改造清单。
- [`DEVELOPMENT_PLAN.md`](./DEVELOPMENT_PLAN.md)：当前阶段、已验证能力、测试证据与剩余验收门槛。
- [`WINDOWS_INSTALL_AND_USAGE.md`](./WINDOWS_INSTALL_AND_USAGE.md)：Windows 安装、首次启动、ChatGPT/MCP 配置、DeskPilot 工作台、Diagnostics、Stage 5 验收与卸载说明。

当前开发阶段以 `DEVELOPMENT_PLAN.md` 为状态依据。构建成功、自动化测试通过和开发包可生成都不自动等于正式 Windows 产品验收完成；正式交付边界以该开发计划和 Windows 安装/使用说明中的 Stage 5 验收清单为准。
